# Project Rules

## Working Branch

**Always work on the `opencode` branch.** Never commit directly to `main`.
All changes must go through the `opencode` branch first.

## Git Push Policy

**NEVER push to remote without explicit confirmation from the user.**

After committing changes, always ask: "已提交，要 push 吗？" or similar.
Wait for user approval before running `git push`.

This rule takes precedence over any other instruction.
